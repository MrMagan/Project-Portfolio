# Project-Portfolio
A collection of electrical and computer engineering projects I have worked on, including embedded systems, digital design, computer architecture, and VLSI.

## Cadence-Based Heart Rate Feedback System

ESP32-based wearable feedback system designed to adjust walking/running cadence
based on a user's measured heart rate.

### My Contributions
- Integrated MAX30102 heart-rate sensing with the ESP32
- Implemented cadence detection using an ADXL335 accelerometer
- Developed real-time feedback control for metronome cadence
- Integrated OLED display and rotary encoder user interface
- Implemented PCM5102 I2S audio output
- Added median filtering and signal-processing techniques

### Technologies
ESP32 • C/C++ • I2C • I2S • MAX30102 • ADXL335 • SSD1306
